This program is used to track spending habits and to keep track of recurring payments. Currently it stores user defined groups in a dictionary which is persistant and is stored in a json file. The program accesses this file and makes reads and writes to it based on user input. It also is able to create a pie chart with matplotlib which shows the user which groups are the most prominent. In future implementations, I would like to add a GUI and fix a bug with the recurring variable. I would also like to implement the data structure as a class so that I can store purchases individually though this project is put on a pause for now as I develop my AI inplemented to do list.
